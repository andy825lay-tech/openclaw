# NEUXA / TLS 星群自動化場景清單

> 作者：阿策（COO）| 日期：2026-03-21  
> 審核：阿維（DevOps）

---

## 背景

本文件由阿策（COO）統整，列出 8 個適合 NEUXA（LINE 官方帳號平台）與 TLS 星群科技實際營運的自動化場景。這些場景全部使用 **n8n + Ollama 本地 LLM**，無需昂費的雲端 API 費用。

---

## 場景清單

### 場景 1：LINE 智能客服機器人

**適用對象：** NEUXA 企業用戶  
**觸發條件：** 用戶傳送訊息至 LINE 官方帳號  
**流程：**

1. n8n 接收 LINE Webhook 事件
2. 整理對話歷史（最近 5 輪）
3. 呼叫 `tls-phi4:latest` 判斷意圖（諮詢/抱怨/購買/其他）
4. 若為常見問題，直接從知識庫檢索回覆
5. 若為複雜問題，生成初步回覆草稿，標記「需人工確認」
6. 回傳 LINE 回應

**LLM 使用模式：** `/api/chat`（多輪對話）  
**預計節省人力：** 60-70% 的重複問題可自動化

---

### 場景 2：每日營運報告自動生成

**適用對象：** TLS 星群內部管理  
**觸發條件：** 每日早上 09:00 定時觸發  
**流程：**

1. n8n 從 Google Sheets / Notion 抓取昨日 KPI
2. 呼叫 `tls-gemma3:latest` 生成圖文分析報告
3. 生成 Discord 訊息，附上關鍵指標
4. 發送至 #daily-reports 頻道

**LLM 使用模式：** `/api/generate`（單次生成）  
**預計節省時間：** 每次 30 分鐘 → 自動化 0 分鐘

---

### 場景 3：Email 詢價自動回覆

**適用對象：** TLS 星群商務團隊  
**觸發條件：** 新 email 進 Gmail / 官網表單  
**流程：**

1. n8n 監聽 Gmail 新信件（或 Zapier 轉發）
2. LLM 分析詢價內容，提取：產品型號、數量、需求
3. LLM 生成初步報價草稿
4. 發送至商務團隊 Discord 待確認
5. 確認後自動回覆客戶

**LLM 使用模式：** `/api/generate`  
**預計節省人力：** 80% 初步回覆可自動化

---

### 場景 4：社群內容創作者

**適用對象：** NEUXA 行銷團隊 / TLS 星群  
**觸發條件：** 每週一、三、五 自動觸發  
**流程：**

1. 抓取當週熱門話題（關鍵字監控）
2. 呼叫 `tls-qwen3:latest` 生成 3 個不同風格的社群貼文
3. 搭配圖片生成（可用 image_generate 工具）
4. 排程發布至 LINE 官方帳號 / Instagram / FB

**LLM 使用模式：** `/api/generate`  
**預計產出：** 每週 3-5 篇 SEO 優化內容

---

### 場景 5：Bug 自動分類與 Issue 建立

**適用對象：** TLS 星群開發團隊  
**觸發條件：** GitHub / GitLab 新 Issue 或錯誤日誌進來  
**流程：**

1. n8n 接收錯誤報告（Error log 或 Issue 描述）
2. 呼叫 `deepseek-r1:7b`（推理能力強）分析問題類型
3. 自動分類：UI Bug / API Error / 效能問題 / 文件問題
4. 評估嚴重性：P0/P1/P2/P3
5. 自動建立 GitHub Issue，附加標籤與指派

**LLM 使用模式：** `/api/generate`  
**預計節省時間：** 工程師每日節省 20-30 分鐘分類時間

---

### 場景 6：LINE 語音訊息轉文字 + 處理

**適用對象：** NEUXA 企業用戶 / TLS 星群  
**觸發條件：** 用戶傳送語音訊息  
**流程：**

1. n8n 接收 LINE 語音訊息
2. 下載音檔，呼叫 Whisper API 轉文字
3. LLM 分析意圖 → 生成回覆
4. 回傳文字訊息或圖文訊息

**LLM 使用模式：** `/api/chat`  
**技術需求：** Whisper（可本地部署或用雲端）

---

### 場景 7：競爭對手監控快報

**適用對象：** TLS 星群策略團隊  
**觸發條件：** 每週一早上  
**流程：**

1. n8n 爬蟲抓取競爭對手網站更新、新聞
2. LLM 整理成「每週競爭情報摘要」
3. 分類：產品動態定價策略、法規變化、行銷活動
4. 發送至 #strategy 頻道，存入 Notion 資料庫

**LLM 使用模式：** `/api/generate`  
**預計價值：** 每週节省 2-3 小時的情報收集時間

---

### 場景 8：內部知識庫 Q&A 系統

**適用對象：** NEUXA 企業內部 / TLS 星群全體  
**觸發條件：** 員工傳送問題至指定 LINE 群組或 Slack  
**流程：**

1. 員工輸入問題
2. 先用 `nomic-embed-text` 做向量相似度比對（檢索知識庫）
3. 若找到相關內容，LLM 組織答案回覆
4. 若無相關內容，標記「待補充」，轉發給負責人
5. 知識庫持續學習

**LLM 使用模式：** `/api/chat` + 向量檢索  
**預計價值：** 減少重複回答相同問題
