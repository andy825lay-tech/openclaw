## 1. 設計方向總覽

### 1.1 配色方案

| 用途             | 色碼                  | 說明                |
| ---------------- | --------------------- | ------------------- |
| 主色（品牌藍）   | `#1E3A5F`             | 信任感、專業、商務  |
| 輔色（科技紫）   | `#6B5CE7`             | AI 科技感、年輕活力 |
| 強調色（能量橙） | `#FF6B35`             | CTA 按鈕、重要指標  |
| 背景漸層         | `#0D1B2A` → `#1B2838` | 深色系，沈浸感      |
| 文字主色         | `#FFFFFF`             | 高對比清晰閱讀      |
| 文字輔色         | `#A8B4C4`             | 次要資訊說明        |

### 1.2 構圖原則

- **黃金三分法**：將畫面橫向/縱向分為三等份，核心資訊置於交點
- **呼吸感**：元素間距一致（間距基數 8px），留白不少於畫面 20%
- **聚焦引導**：使用漸層遮罩或引導線，將視覺動線引導至 CTA

### 1.3 風格關鍵字

```
極簡科技風 × 漸層動態感 × 數據可視化 × 卡片模組化
```

### 1.4 品牌標語（已確認）

- **主標語**：「一站式 AI 客服：三渠道無縫接軌，企業服務永不掉線」
- **目標受眾**：電商零售、SaaS、金融科技等中型企業
- **核心賣點**：三渠道統一、AI 秒級回覆、CRM 整合、快速上線、數據驅動

- 圖示：線條型（Line Icon），粗細 1.5px
- 字體：無襯線英文字體（Inter / SF Pro Display）
- 動效：建議以 CSS 漸層位移為主，避免過多重度 JS 動畫
- 圓角：8px（小元件）/ 16px（卡片）/ 24px（主面板）

## 2. 三個主要展示區塊 — 視覺規格

### 2.1 區塊 A：Header Hero（展示版頭圖）

**尺寸规格**

- 全寬橫幅，建議比例 16:5（例：1600×500px）
- 響應式縮放，斷點設定 768px / 1200px

**視覺元素**

- 背景：深色漸層（`#0D1B2A` → `#1B2838`）疊加幾何光暈（紫色 `#6B5CE7` 透射，opacity 0.15）
- 左側：品牌 Logo + 主標語（白色粗體）
- 中央偏右：三個渠道圖示（LINE / Facebook / Website），以發光連線串聯，象徵「三渠道統一接入」
- 右下角：小區塊標註「AI Powered」標籤（橙底白字 pill badge）

**字體規格**

- 主標語：36px / font-weight: 700 / `#FFFFFF`
- 副標語：18px / font-weight: 400 / `#A8B4C4`

---

### 2.2 區塊 B：Three-Channel Flow（渠道串接示意）

**尺寸规格**

- 佔地 1200×600px（全寬以內最大可用區塊）
- 三欄均分，欄間距 48px

**視覺元素**

- 每欄為一張卡片，白底（`#FFFFFF`）搭配 1px 淺灰邊框
- 卡片頂部：渠道專屬色標示（LINE 綠 `#00B900` / Facebook 藍 `#1877F2` / Website 紫 `#6B5CE7`）
- 卡片內：
  - 渠道圖示（48×48px）
  - 渠道名稱（20px bold）
  - 接入示意截圖（Mockup，灰底佔位）
  - 「已接入」狀態標籤（綠色 pill badge）
- 欄間連接線：虛線箭頭，`#A8B4C4`，從左至右表示「統一進入 AI 處理層」

**卡片動效**

- Hover：Y 軸上移 4px，陰影加深（`box-shadow: 0 12px 32px rgba(0,0,0,0.15)`）

---

### 2.3 區塊 C：情境案例展示

**尺寸规格**

- 佔地 1200×500px
- 三欄均分，欄間距 32px

**視覺元素**

- 每欄為一行業案例卡片
- 卡片頂部：行業圖示 + 行業名稱（電商零售 / SaaS / 金融科技）
- 卡片內容：該行業痛點（1句）+ AI 客服解決方案（2-3句）
- 卡片底部：「已服務 ▲XX 家企業」標籤
- 行業代表色：電商 `#FF6B35`（橙）/ SaaS `#6B5CE7`（紫）/ 金融 `#00D4AA`（青）

**Hover 效果**

- Y 軸上移 4px + 邊框變為行業代表色

---

### 2.4 區塊 D：AI Response Demo（智能回覆展示）

**尺寸规格**

- 佔地 1200×500px
- 左右分欄：左 40%（對話展示）/ 右 60%（數據儀表板）

**左側：對話展示區**

- 背景：`#1E3A5F`（品牌深藍）
- 三條模擬訊息（User / LINE / Facebook / Web），以氣泡呈現
- 氣泡最大寬度 70%，圓角 16px
- User 氣泡：右側對齊，白色背景
- AI 回覆氣泡：左側對齊，深色背景（`#2A3F5F`）

**右側：數據儀表板**

- 四格 KPI 卡片（2×2 grid）
  - 本日相談量
  - 平均回覆時間
  - 解決率
  - 客戶滿意度
- 每格：數字突出（48px bold）+ 趨勢箭頭（↑↓）+ 標籤（14px）
- 底部：甜甜圈圖（渠道分配比例）

**配色呼應**

- LINE 綠 / Facebook 藍 / Web 紫 三色在圖表中各對應一個區塊
