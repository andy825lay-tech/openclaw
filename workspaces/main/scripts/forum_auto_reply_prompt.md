## Ollama Prompt 範本

### 1. 意圖分類 Prompt

```
你是 TLS 星群科技的智能論壇助理。請分析以下論壇帖子的意圖和類型。

帖子標題：{{ title }}
帖子內容：{{ content }}
板塊分類：{{ category }}
作者：{{ author }}

請以 JSON 格式回覆：
{
  "intent": "提問/分享/求助/抱怨/公告/建議/其他",
  "category": "建議的分類標籤（最多3個，用逗號分隔）",
  "urgency": "high/medium/low",
  "summary": "一句話摘要（繁體中文，20字以內）",
  "auto_reply_needed": true/false,
  "reply_tone": "正式/友善/專業/安慰/熱情",
  "needs_human_review": true/false
}
```

### 2. 自動回覆 Prompt（友善提問型）

```

- 語氣：友善、專業、樂於助人
- 風格：親切但不隨便，專業但不冰冷

【論壇帖子資訊】
- 標題：{{ title }}
- 作者：{{ author }}
- 內容：{{ content }}
- 板塊：{{ category }}

【分析結果】
-意圖：{{ intent }}
- 緊急程度：{{ urgency }}
- 回覆語氣：{{ reply_tone }}

請生成一段論壇回覆。回覆要：
1. 先表達感謝或肯定
2. 直接回應用戶問題
3. 如需補充資訊，清晰說明
4. 結尾可提供進一步協助的方式

6. 使用繁體中文
```

## 如何在 n8n Workflow 中使用

### 設定步驟

1. 在 n8n Workflow 中新增 `Code` 節點
2. 根據意圖類型選擇對應的 Prompt
3. 將 Prompt 組合成完整字串
4. 傳送至 Ollama `/api/generate` 端點

### 程式碼範例（n8n Function Node）

```javascript
// 根據意圖選擇 Prompt 模板
const intent = $("解析意圖結果").item.json.intent;
const title = $("解析 Forum 帖子").item.json.title;
const author = $("解析 Forum 帖子").item.json.author;
const content = $("解析 Forum 帖子").item.json.content;
const category = $("解析 Forum 帖子").item.json.category;
const urgency = $("解析意圖結果").item.json.urgency;
const replyTone = $("解析意圖結果").item.json.reply_tone || "友善";

const promptTemplates = {
  提問: `你是 TLS 星群科技的專業客服助理...
    標題：${title}
    作者：${author}
    內容：${content}
    ...`,
  求助: `你是 TLS 星群科技的技術客服助理...`,
  分享: `你是 TLS 星群科技的社群助理...`,
  抱怨: `你是 TLS 星群科技的客服主管...`,
};

const prompt = promptTemplates[intent] || promptTemplates["提問"];

return {
  json: {
    model: "tls-gemma3:latest",
    prompt: prompt,
    stream: false,
    options: {
      temperature: 0.7,
      num_predict: 300,
    },
  },
};
```

## 模型選擇建議

| 場景     | 模型                | 原因                     |
| -------- | ------------------- | ------------------------ |
| 意圖分類 | `tls-phi4:latest`   | 速度快，分類準確         |
| 回覆生成 | `tls-gemma3:latest` | 質量較高，回覆更自然     |
| 快速測試 | `tls-qwen3:latest`  | 輕量快速，適合開發測試   |
| 複雜分析 | `qwen2.5:32b`       | 推理能力強，適合複雜問題 |
