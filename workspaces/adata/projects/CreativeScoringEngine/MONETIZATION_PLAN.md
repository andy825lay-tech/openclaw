## 一、產品能力評估（假設情境）

| 功能         | 描述                                            |

| 批量處理     | 支援一次分析多個創意                            |
| 歷史追蹤     | 記錄評分歷史，追蹤創意演進                      |

## 二、定價方案

### 方案 A：Freemium 免費增值模型（推薦）

| 方案         | 免費版   | 付費版 Pro          |
| ------------ | -------- | ------------------- |
| **價格**     | 免費     | **$9.9 / 月**       |
| **每日額度** | 5 次/天  | **無限次**          |
| **功能限制** | 基礎評分 | 全部功能 + 優先處理 |
| **支援**     | 社群     | 電子郵件支援        |

**月收入預估（樂觀情境）：**

| 指標              | 預估              |
| ----------------- | ----------------- |
| 免費用戶轉化率    | 3-5%              |
| 100 名免費用戶/月 | 3-5 名付費用戶    |
| 月收入預估        | **$30-50 / 月**   |
| 年收入預估        | **$360-600 / 年** |

**問題診斷：**  
$9.9/月 對台灣市場偏低，建議：

- **個人版 $4.99/月**（免費5次/天 → 30次/天）
- **專業版 $14.99/月**（無限 + 批次 + API）

### 方案 B：一次性付費（不推薦）

| 方案     | 價格               |
| -------- | ------------------ |
| 終身授權 | $49一次性          |
| 問題     | 無法產生持續現金流 |

## 三、收款方式評估

### 1. Stripe（國際/美元收款）✅ 推薦

| 項目           | 評估                                                        |
| -------------- | ----------------------------------------------------------- |
| **覆蓋市場**   | 全球（含台灣）                                              |
| **信用卡支援** | Visa/Mastercard/Amex                                        |
| **手續費**     | 2.9% + $0.30/筆                                             |
| **台灣法規**   | ⚠️ 台灣商家需提供統一編號，個人可用 Stripe Atlas 開美國帳戶 |
| **對外收款**   | ✅ 最優選（收美元）                                         |
| **註冊難度**   | 中等（需國信用卡或 Stripe Atlas）                           |

**TLS 現況：** `~/.secrets/keys.env` 已有 Stripe key，可直接啟用。

### 2. 綠界科技 ECPay（台灣本幣收款）✅ 必備

| 項目         | 評估                       |
| ------------ | -------------------------- |
| **覆蓋市場** | 台灣為主                   |
| **付款方式** | 信用卡、超商、ATM、條碼    |
| **手續費**   | 2.5-3%（依方案）           |
| **台幣收款** | ✅ 直接收 TWD              |
| **出金**     | 自動匯入台灣銀行帳戶       |
| **註冊難度** | 中等（需公司或工作室登記） |

**建議：** 個人接案者可先用「綠界個人收款」，免註冊公司。

### 3. 歐富 PAY（台灣新創）🟡 備選

| 項目         | 評估                         |
| ------------ | ---------------------------- |
| **覆蓋市場** | 台灣為主                     |
| **特色**     | API 友善、快速接入           |
| **手續費**   | 2.5%                         |
| **台幣收款** | ✅                           |
| **建議**     | 可作為綠界備選，兩者同時支援 |

### 收款策略建議

```
對外（美元玩家、國際用戶）→ Stripe（首選）
台灣用戶 → 綠界 ECPay（必備）
備選 → 歐富 PAY
```

## 六、本地 AI API（Ollama）對外收費可行性

### 技術可行性：✅ 可行

TLS 現有基礎設施：

- Ollama 已運行（:11434）
- 多模型組合（mistral:7b、qwen2.5:32b 等）
- Docker + PostgreSQL 已就緒

### 變現方案

| 方案             | 說明                               | 收費建議                   |
| ---------------- | ---------------------------------- | -------------------------- |
| **API 按量計費** | 對外開放 Ollama API，按 token 計費 | $0.01-0.05/1K tokens       |
| **月費套餐**     | 基礎/專業/企業三級                 | $9.99 / $29.99 / $99.99/月 |
| **私有部署**     | 幫企業在本地部署 Ollama + 客製化   | $500-2000/次               |

### 風險與限制

| 風險     | 等級  | 說明                                 |
| -------- | ----- | ------------------------------------ |
| 頻寬瓶頸 | 🟡 中 | Mac Studio 上傳頻寬有限              |
| 硬體成本 | 🟡 中 | M3 Ultra 96GB 同時服務人數有限       |
| 競爭壓力 | 🔴 高 | OpenRouter、Anthropic API 價格戰激烈 |
| 法律合規 | 🟡 中 | 對外營利需注意資料隱私法規           |
| API 文件 | 🟢 低 | 需建立 API 開發者文件                |

### Ollama 對外收費建議

```
結論：技術可行，但面臨競爭激烈 + 頻寬限制。

建議策略：
1. 【不對外收費】作為 TLS 內部核心競爭力
2. 【差異化】對外強調「本地部署、隱私優先」特色
3. 【HaaS 模式】將 Ollama 能力包裝進 HaaS 服務（月費制）
4. 【測試水溫】先對外開放免費 API → 收集使用者 → 再收費
```
